# Personal Assistant with Supervisor Pattern

A LangChain multi-agent personal assistant using:

- Supervisor Agent
- Calendar Agent
- Email Agent
- Human-in-the-Loop Approval
- LangGraph Checkpointing

## Features

✅ Schedule Meetings

✅ Check Availability

✅ Send Emails

✅ Multi-Agent Routing

✅ Human Approval Before Actions
